# Plugy Engine

Небольшая CMS на PHP для MySQL и MariaDB. В комплекте демо-сайт студии с главной страницей и журналом. В админке можно добавлять, редактировать, скрывать, переставлять и удалять блоки главной, а также сохранять черновики и публиковать статьи.

## Локальный запуск

Нужен PHP 8.3+ с расширением `pdo_mysql` и запущенный MySQL или MariaDB. На Windows включите `extension=pdo_mysql` в активном `php.ini` и проверьте наличие модуля командой `php -m`. Создайте пустую базу и предоставьте пользователю доступ к ней.

Из корня проекта:

```shell
php -S 127.0.0.1:8080 -t public
```

Откройте [сайт](http://127.0.0.1:8080/) или [админку](http://127.0.0.1:8080/admin/). Установщик запросит параметры базы, затем предложит задать пароль для логина `admin`.

## Установка на обычный PHP-хостинг

1. В панели хостинга включите PHP 8.3 или новее и `pdo_mysql`. Создайте пустую базу MySQL или MariaDB и назначьте ей пользователя с правами чтения, записи и создания таблиц.
2. Распакуйте подготовленный архив прямо в корневую папку домена, например `public_html/`. Файл `index.php` и папки `admin/`, `app/`, `public/` должны оказаться на одном уровне. Если домен показывает стандартную заглушку, переместите существующий `index.html` заглушки из папки сайта.
3. Откройте домен по HTTP или HTTPS. Введите название базы, имя пользователя, пароль и хост. Порт по умолчанию — `3306`.
4. После проверки подключения задайте пароль для логина `admin`. Plugy сохранит подключение, создаст таблицы, добавит демо-контент и откроет страницу входа.

Загружайте только файлы из подготовленного архива. Если вы уже загрузили старый `app.zip` и распаковали папку `var/`, переместите архив и папку за пределы корня сайта. В обоих могут быть данные и сессии предыдущей установки.

По умолчанию установка из архива создаёт отдельную папку `.plugy-…` рядом с корневой папкой сайта. В ней хранятся файл подключения и сессии. Если хостинг ограничивает запись в соседние папки, укажите в `app/install.local.php` параметр `data_directory` с абсолютным путём к закрытой папке, доступной PHP для записи. Например, `/home/account/plugy-data`.

Существующие установки на SQLite продолжают работать через `pdo_sqlite`. При переносе прежней установки укажите закрытую папку с файлом `plugy.sqlite`. Перед переносом базы с локальным паролем смените его в админке локального сайта.

На тестовых доменах можно работать по HTTP. На публичных сайтах HTTPS шифрует пароль и сессионную cookie при передаче. Если TLS завершается перед PHP, настройте веб-сервер так, чтобы для защищённых запросов PHP получал параметр `HTTPS=on`.

При установке **из исходников** можно указать `public/` как корневую папку веб-сервера. На публичном домене завершите установку сразу после загрузки файлов. До первого успешного запуска форма доступна посетителям сайта.

Встроенный сервер PHP предназначен для локальной разработки. Для резервного копирования используйте экспорт MySQL или MariaDB и сохраняйте копию файла подключения из закрытой папки данных.

## Редактор кода

В админке откройте «Редактор кода». Сайт использует шаблоны из `app/theme/`. Главная и журнал находятся в `home.html`, разметка блоков в `block.html`, страницы статей и карточки в `article.html` и `article-card.html`. Общая шапка и подвал находятся в `index.html`, стили в `styles.css`, скрипт в `script.js`. В шаблон подставляются данные сайта через переменные вида `{{title}}`. Тексты статей и блоков можно править в одноимённых разделах админки. Изменения кода публикуются при сохранении и хранятся в папке `theme/` внутри закрытой папки данных.

## Как устроено

- `index.php` и `admin/index.php` — точки входа для обычного хостинга. `public/` — приложение и статические файлы. `app/` — логика, схема базы и шаблоны. При локальном запуске с `-t public` параметры подключения и сессии хранятся в `var/`.
- Для блоков доступны три типа: «Первый экран», «Текстовая секция» и «Акцентный блок». Текст статьи вводится обычным текстом с переносами строк. Адрес статьи можно указать вручную или оставить пустым для автогенерации.
- Пароль хранится в виде хеша Argon2id, при отсутствии поддержки используется bcrypt. Сессии хранятся на сервере, ID обновляется после входа и смены пароля. Формы защищены CSRF-токеном. Вход ограничен по IP и учётной записи, а смена пароля завершает остальные сессии.
